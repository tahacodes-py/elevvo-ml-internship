
# Elevvo ML Internship

Machine learning tasks completed as part of the Elevvo Pathways internship,
covering regression, clustering, classification, and evaluation techniques
using Python and Scikit-learn.

## Tasks

### Task 1: Student Score Prediction
Predicts students' exam scores from study hours using linear regression.

- **Dataset:** [Student Performance Factors](https://www.kaggle.com/datasets/lainguyn123/student-performance-factors) (Kaggle)
- **Approach:** Data cleaning, train/test split, linear regression, evaluation via RMSE and R²
- **Result:** RMSE ≈ 3.29, R² ≈ 0.231 (study hours alone explains ~23% of score variance — exploring additional features next)
- **Files:** [`task1.py`](./task1.py)
